# TG群组智能补集

群成员在 Telegram 群里发「TMDB ID + 缺哪集 / 哪集有问题」，插件自动识别 → MoviePilot 精确搜索 → 挑出对应集的资源 → 点按钮（或全自动）下载。

## 准备

1. 在 @BotFather 新建一个机器人（**不要**和 MoviePilot 自带的 Telegram 通知共用一个 Token，同一个 Token 只能有一个程序收消息）。
2. 在 @BotFather 用 `/setprivacy` 把机器人设为 **Disable**，否则群里只能收到 `/` 命令。
3. 把机器人拉进群，在插件配置里填 Token、启用。
4. 国内网络需打开「使用系统代理访问 Telegram」，并在 MoviePilot 里配置好代理。

## 能识别的说法

| 群消息 | 识别结果 |
|---|---|
| `tmdb 12345 缺第5集` | E05，缺集 |
| `tmdbid:12345 S02E05 资源有问题` | S02 E05，重下 |
| `https://www.themoviedb.org/tv/12345 第二季 3-5集 花屏` | S02 E03-E05，重下 |
| `12345 第3、7、9集没有` | E03 E07 E09，缺集 |
| `tmdb=12345 s1 e3 e4 字幕错了` | S01 E03 E04，重下 |
| `/mp 12345 S03 第二十一集` | S03 E21 |
| `tmdb 550 电影 资源有问题` | 电影，重下 |
| `tmdb movie 550` / `https://www.themoviedb.org/movie/550` | 电影 |

- 没写季：单季剧自动用那一季，多季剧弹按钮选季。
- 不写集数：按整季搜索；TMDB 查不到这个剧集 ID 时自动按电影搜索。
- 电影和剧集的 TMDB ID 是两套编号，同一个数字可能既是剧又是电影。求电影时最好带上「电影」或写成 `tmdb movie 550`，否则会先按剧集查。
- 纯数字 ID 要求比较严，避免普通聊天误触发：
  - 必须同时带集数或「缺 / 有问题 / 花屏…」之类关键词；
  - 数字必须在消息开头，后面不能跟单位（如 `2016年`、`300 块`、`500G`、`1080p`）；
  - 720、1080、2160 等分辨率数字不当作 ID；
  - 整条消息超过 40 字不识别。
  写了 `tmdb 1080` 或 TMDB 链接就不受这些限制。
- 群里发公告、教程不会误触发：超过 120 字、超过 3 行，或一条消息里提到多个 TMDB ID 的都不自动识别；确实要这样发时用 `/mp` 开头。也可以在配置里关闭纯数字 ID，或改成只响应 `/mp`。

## 先查媒体库

求片和缺集在搜索前会先查 MoviePilot 连接的媒体库（可在配置里关闭「求片前先查媒体库」）：

- 电影已在库里：直接回复「已经在库里了，可以直接去看」，不搜索、不扣积分。
- 剧集（综艺在 TMDB 里也是剧集）：
  - 点名的集都在库里：同样直接回复，不下载；
  - 部分在库里：只下缺的集，并说明哪些已在库里；
  - 只写了季没写集：按 TMDB 的集数对照，整季都在就不下，否则只补缺的集。
- 报资源有问题的（花屏、没字幕、音画不同步等）不查库，照常重新下载别的版本。
- 查询媒体库出错时不拦截，照常搜索下载。

## 选资源

默认自动下载排第一的资源，不用点按钮；第一个推送失败会自动换下一个候选。关掉「自动下载最优资源」后改为列出候选让发起人或管理员点按钮。

每集候选按以下顺序排，兼顾速度和画质：

1. 做种数低于「做种少于此数排到最后」（默认 3）的放最后，基本下不动；低于「最少做种数」的直接不要。
2. 画质：MoviePilot 优先级规则组的匹配等级，规则里越靠前越优先。
3. 每集大小：多集包 / 整季包按集数平均，从 256MB 起每翻一倍算一档，档位高的优先；差不多大的（同一档）再往下比。
4. 做种数分档（≥100 / ≥30 / ≥10 / ≥3），档位高的优先。
5. 免费优先。
6. 单集 > 含该集的多集包 > 整季包。
7. 最后按做种数和 MoviePilot 原始顺序。

每次搜索后，插件日志会列出每集前几个候选的做种数、每集大小、是否免费和规则等级，选得不对时可以对照查看。

所以画质偏好请在 MoviePilot 的优先级规则组里设置（如 2160p > 1080p、WEB-DL > HDTV）。

- 选中多集包或整季包时，只勾选本次请求里它覆盖的集，其余文件不下载。
- 一次请求多集时，同一个包覆盖的几集只下载一次。
- 群里只显示集数、大小、做种数、促销和资源标题，不显示站点名；标题末尾的发布组后缀（如 `-XXWEB`）也会去掉，避免暴露来源站点。下载记录页仍保留完整标题。
- 「资源有问题」和「缺集」走同一套流程；旧文件是否被替换取决于 MoviePilot 整理的覆盖模式（建议「按大小」或「覆盖」）。

## 自动删除群消息

- 机器人处理完一次求片（已推送、没搜到、积分不足、取消等）后，默认 3 分钟删除它发的消息；还有按钮没点的，等任务过期（1 小时）再删。
- 打开「同时删除群友的求片消息」会连原消息一起删，需要机器人是群管理员并有删除消息权限。
- 入库提醒默认保留，也可以设置几分钟后删除。
- 待删除列表会保存，插件重启后照样按时删；Telegram 只允许删除 48 小时内的消息。

## 入库提醒

下载推送成功后，插件会记下是谁求的。MoviePilot 整理完成时按下载任务对上请求，在群里回复原消息并 @ 求片的人：「你求的《xx》S01 E05 已入库，可以去看了」。超过「等待入库天数」（默认 7 天）还没入库的就不再提醒。

## PMS 积分（可选）

对接 PMSManageBot 的积分，需要 PMSManageBot 里配置 `MP_CREDITS_API_TOKEN`，插件里填同一个密钥和 PMS 地址。

- 价格：电影按部、剧集按季收（默认电影 10、每季 20）。
- 每月免费额度：默认 3 部电影、2 季剧集，每月 1 号重置，先用额度，用完再扣积分。
- 求片前检查：有额度或积分够才搜索，不够直接回复「积分不足」；没在 PMS 绑定的会提示先绑定。
- 入库后才结算：没入库（没搜到、下载失败、超时）不收。
- 同一个人求同一部电影 / 同一季只收一次，后面再补这季的其他集不再收。
- 「资源有问题」重下免费；管理员默认免费（可关）。

## 权限

- 「允许的群组 ID」留空则任何拉了机器人的群都能用，建议填上。
- 按钮只有发起人和「管理员 TG 用户 ID」里的人能点。
